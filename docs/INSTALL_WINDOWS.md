# Install on Windows
1. Download this repository as a ZIP and extract it, or clone it with Git.
2. Locate the Skill directory used by your installed DSH version/profile. Layouts can differ; inspect DSH settings or its Skills manager rather than assuming a universal path.
3. Copy `skills\\dsh-autonomous-worker\\` into that Skill directory. Keep the folder name `dsh-autonomous-worker`.
4. Refresh/reload Skills in DSH, or restart DSH if required by your version.
5. Confirm `dsh-autonomous-worker` appears in the installed Skills list and that `SKILL.md` is readable.
6. Run the harmless smoke test in [USAGE.md](USAGE.md).
No administrator privileges, paid model, API key, or extra package is required by this Skill itself.
